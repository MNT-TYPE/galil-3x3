# אליפות הגליל 3X3 – מערכת ניהול הטורניר

אפליקציית דף יחיד (HTML + JavaScript, ללא שרת) לניהול והצגה של טורניר כדורסל 3X3:
לוח זמנים לפי שעה ומגרש, בתים וטבלאות, כרטיסי קבוצות ושחקנים, לוח לפי מגרש, וממשק ניהול להזנת הנתונים.

## קבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | האפליקציה כולה (עיצוב, תצוגות, ניהול, בדיקות תקינות). מקור האמת. |
| `seed.json` | נתוני הטורניר 2026 כפי שהועתקו מהגיליונות המקוריים. נטען אוטומטית בהרצה מקומית ראשונה. |
| `tools/make_seed.py` | מייצר את `seed.json` מתוך הטבלאות שבקובץ (קל לערוך שם ולהריץ מחדש). |
| `tools/build_static.py` | בונה את `docs/index.html`: דף יחיד, לצפייה בלבד, עם הנתונים והלוגו מוטמעים. |
| `tools/publish.sh` | בנייה + commit + push ל-GitHub Pages בפקודה אחת (מקבל קובץ גיבוי מהאפליקציה). |
| `tools/build_artifact.py` | בונה את דף ה-Artifact: גוף `index.html` + נתונים מוטמעים + לוגו. |
| `assets/logo-*.jpg` | סמל הפועל גליל עליון (המקור והגרסה המוקטנת שמוטמעת בדף). |
| `.claude/launch.json` | הגדרת שרת פיתוח מקומי (python http.server על פורט 8765). |

## הרצה מקומית

```bash
python3 -m http.server 8765
```

ואז פותחים `http://localhost:8765`. במצב זה הנתונים נטענים מ-`seed.json` ושינויים נשמרים כטיוטה ב-localStorage של הדפדפן. "ניהול → גיבוי" מאפשר ייצוא/ייבוא JSON.

## הקישור להורים: GitHub Pages (ללא התחברות)

דף ה-Artifact ב-claude.ai דורש התחברות לצפייה, ולכן הקישור שנשלח להורים הוא עותק **לצפייה בלבד** שמתארח ב-GitHub Pages
מתוך התיקייה `docs/` (ללא לשונית ניהול, בלי צורך בחשבון).

הקמה חד-פעמית:
1. יוצרים ב-github.com מאגר ציבורי חדש (למשל `galil-3x3`), ריק, בלי README.
2. מחברים ודוחפים:
   ```bash
   git remote add origin https://github.com/<USER>/galil-3x3.git
   git push -u origin main
   ```
3. במאגר: Settings → Pages → Build and deployment → Source: *Deploy from a branch* → Branch: `main`, Folder: `/docs` → Save.
4. אחרי דקה הקישור להורים הוא `https://<USER>.github.io/galil-3x3/`.

עדכון הלוח (תוצאות, שינויי שעות):
1. עורכים בלשונית ניהול – בגרסה המקומית (`python3 -m http.server 8765`) או ב-Artifact.
2. ניהול → גיבוי → "הורדת קובץ גיבוי".
3. מריצים:
   ```bash
   tools/publish.sh ~/Downloads/galil-3x3-2026-….json
   ```
   הסקריפט מעתיק את הגיבוי ל-`seed.json`, בונה מחדש את `docs/index.html`, מבצע commit ו-push. ההורים רואים את העדכון תוך כדקה.

## גרסת העורך ב-claude.ai (Artifact)

הדף מפורסם כ-Artifact ב-claude.ai. **הנתונים מוטמעים בתוך הדף עצמו**, ולכן כל מי שמקבל את הקישור
(גם בלי חשבון Claude) רואה את הלוח המלא – מתאים לשיתוף בקבוצת וואטסאפ של ההורים.

- **בעל הדף** רואה לשונית "ניהול". כל שינוי נשמר כטיוטה בדפדפן שלו, ובלחיצה על **"פרסום לכולם"** הדף
  מפרסם את עצמו מחדש עם הנתונים החדשים (יכולת `artifact` של claude.ai). להורים אין לשונית ניהול.
- כדי שההורים יוכלו לפתוח: בתפריט Share של ה-Artifact לבחור שיתוף בקישור לכל אחד.
- "הקבוצה שלי": כל הורה מסמן את הקבוצה של הילד/ה; הסימון נשמר בטלפון שלו בלבד ומציג את המשחק הבא בראש הדף.

לפרסום מחדש מהמחשב (אחרי שינוי ב-`index.html`, או כדי לטעון גיבוי שיוצא מהאפליקציה):

```bash
python3 tools/build_artifact.py dist/galil-3x3.html --data seed.json
```

ואז לפרסם את `dist/galil-3x3.html` לאותו קישור (ב-Claude). הסקריפט מטמיע את הנתונים ואת הלוגו בתוך הדף.

## מודל הנתונים

- `settings/main` – שם הטורניר, שנה, תאריך, מיקום, רשימת מגרשים (לפי סדר ההצגה), קטגוריות.
- `teams/<id>` – `{name, categoryId, players[], order}`
- `houses/<id>` – `{name, categoryId, teamIds[], order}`
- `games/<id>` – `{categoryId, houseId, stage, time, court, teamA, teamB, labelA, labelB, scoreA, scoreB, order}`
  - `stage`: `house | quarter | semi | third | final | other`
  - `teamA/teamB` הם מזהי קבוצות; כשריקים מוצג `labelA/labelB` (למשל "מקום 1 בית א׳").
  - הזנת `scoreA/scoreB` מעדכנת אוטומטית את טבלת הבית (ניצחונות → הפרש → נקודות זכות).

## בדיקות תקינות אוטומטיות

הלשונית "ניהול" מציגה בכל רגע: שני משחקים באותו מגרש ובאותה שעה, קבוצה שמשובצת לשני משחקים
במקביל, קבוצה שמשחקת בבית שאינה חברה בו, קבוצה שלא מתאימה לקטגוריה, משחק ללא שעה/מגרש,
וזוגות בבית שעדיין לא נפגשו. שגיאות מסומנות באדום גם בלוח הזמנים.

## הערות על הנתונים המקוריים

- ז'-ח' בשעה 11:30: בית א' ובית ג' רשומים שניהם על דחר 1 (ככל הנראה בית א' אמור להיות על דחר 2).
- קטסל בשעה 10:15: משחק מקומות 3-4 והגמר רשומים שניהם על דחר 1.
- בית ה' (קטסל): בגיליון נכתב "איילת השחר 1" במשחקי הבית, אך חברת הבית היא איילת השחר 2 – הוזן 2.
- ג'-ד': בטבלת הבתים בגיליון חולתה 2 רשומה בבית ב' וחולתה 3 בבית ג', אבל בלוחות המשחקים זה הפוך. הוזן לפי לוחות המשחקים (חולתה 3 בבית ב', חולתה 2 בבית ג').
- ג'-ד': עמודות השחקנים צפופות מאוד; לעמיר 1 לא נקראו שמות, וייתכן שחלק מהשמות בעמודות עמיר/דפנה/חולתה זזו עמודה. לבדוק בלשונית קבוצות.
- כמה שמות שחקנים בגיליון היו קשים לקריאה (בעיקר בעמודות כפר בלום/כפר גלעדי) – כדאי לעבור עליהם בלשונית קבוצות.
